# PG Guardian

## 1. Project Overview

PG Guardian is an AI-powered PostgreSQL operations assistant designed for PostgreSQL DBAs.

The goal of this project is to automate repetitive DBA tasks such as health checks, performance analysis, replication monitoring, backup verification, and AI-assisted diagnostics.

Rather than replacing existing monitoring tools, PG Guardian focuses on helping DBAs understand operational status and recommend appropriate actions.

---

## 2. Goals

- Automate repetitive PostgreSQL DBA tasks
- Analyze PostgreSQL operational metrics
- Detect abnormal conditions
- Provide AI-assisted analysis
- Generate operational reports
- Support PostgreSQL HA environments

---

## 3. Target Users

- PostgreSQL DBA
- Database Engineer
- Technical Support Engineer
